# Data and model availability

## Included now

This initial package contains code, configuration, environment files and documentation only. No training DDI data, 2026 external cohort, derived data cache, generated result table or trained checkpoint is included.

## Planned update

After the accompanying manuscript is accepted, we will upload:

- the training DDI data and authorized derived preprocessing artifacts;
- the 2026 external evaluation cohort and its documented provenance;
- trained model weights and the corresponding checksums;
- generated evaluation results needed to reproduce the reported analyses.

All uploads will follow the redistribution terms of the underlying sources. The README and release notes will be updated with the data/model versions, access instructions and required attribution.
